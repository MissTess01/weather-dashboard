# Weather Dashboard

A web-based weather visualization project developed for the **CSC-20021 Web Technologies Assessment**.

## About the Project

The Weather Dashboard displays weather forecast information for Stoke-on-Trent. It uses PHP to handle project data and JavaScript with Chart.js to visualize weather information.

## Features

- Weather forecast visualization using charts.
- Temperature and humidity data display.
- Average temperature calculation.
- Highest and lowest temperature summaries.
- Average humidity summary.
- Navigation between the Home, CV, and Weather pages.
- Responsive styling using CSS.

## Technologies Used

- HTML
- CSS
- JavaScript
- PHP
- JSON
- Chart.js
- XAMPP
- Git and GitHub

## Project Structure

- `index.php` — Home page.
- `cv.php` — CV page.
- `weather.php` — Weather dashboard.
- `assets/` — CSS and JavaScript files.
- `data/` — Weather forecast data.
- `includes/` — Shared project components.

## How to Run the Project

1. Install and open XAMPP.
2. Start Apache.
3. Place the project folder inside `htdocs`.
4. Open your browser.
5. Visit `http://localhost/csc20021/`.

## Project Purpose

This project demonstrates practical skills in web development, data handling, data visualization, and the integration of PHP, JavaScript, CSS, and JSON.
