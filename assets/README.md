# CSC-20021 Web Technologies Assessment

## Project Title
Weather Dashboard and Personal CV Website

## Project Description
This project is a PHP-based website developed for the CSC-20021 Web Technologies assessment. It contains a homepage, a personal CV page, and a weather dashboard.

## Features
- Homepage with navigation links.
- Personal CV page.
- Weather dashboard displaying weather data.
- Temperature and humidity chart using Chart.js.
- Weather summary showing average temperature, highest temperature, lowest temperature, and average humidity.
- Weather forecast table displaying daily weather information.
- Responsive layout for smaller screens.

## Technologies Used
- HTML
- CSS
- PHP
- JavaScript
- Chart.js
- JSON
- XAMPP

## Project Structure
- `index.php` — Homepage.
- `cv.php` — Personal CV page.
- `weather.php` — Weather dashboard.
- `assets/style.css` — Website styling.
- `assets/script.js` — Weather chart functionality.
- `data/weather.json` — Weather forecast data.
- `includes/` — Shared website components, if used.

## How to Run the Project
1. Install and open XAMPP.
2. Start Apache.
3. Place the project folder inside `C:\xampp\htdocs\`.
4. Open a web browser.
5. Visit `http://localhost/csc20021/`.
